# Tutor Search — гибридный поиск репетиторов на Meilisearch

Небольшой поисковый сервис, который ищет репетиторов **по смыслу**, а не только по точным словам.  
Пользователь пишет «хочу подготовиться к ЕГЭ по математике» — сервис находит репетиторов по математике, даже если в их описании нет слова «ЕГЭ».

В основе — [Meilisearch](https://www.meilisearch.com/) и локальная векторная модель `intfloat/multilingual-e5-small`.

---

## Что умеет

- **Гибридный поиск** — смешивает обычный поиск по словам и поиск по смыслу.
- **Локальные эмбеддинги** — модель работает внутри контейнера, данные не уходят наружу.
- **Русская морфология** — настроены локали и стоп-слова для русского языка.
- **Фильтрация по предмету** — можно сузить поиск до конкретного предмета.
- **Понятный pipeline** — отдельные скрипты для генерации данных, настройки индекса и тестового поиска.

---

## Стек

- **Meilisearch v1.37** — поисковый движок (в Docker).
- **Python 3.9+** — скрипты для работы с индексом.
- **`meilisearch`** — официальный Python-клиент.
- **`python-dotenv`** — конфигурация через `.env`.
- **`intfloat/multilingual-e5-small`** — модель эмбеддингов (скачивается автоматически).

---

## Быстрый старт

### 1. Установить зависимости

```bash
pip install -r requirements.txt
```

### 2. Запустить Meilisearch в Docker

```bash
docker run -d \
  --name meilisearch \
  -p 7700:7700 \
  -e MEILI_MASTER_KEY='ваш_мастер_ключ' \
  -e MEILI_ENV='development' \
  -v meili_data:/meili_data \
  getmeili/meilisearch:v1.37
```

### 3. Создать .env
В корне проекта:

```env
MEILI_URL=http://localhost:7700
MEILI_API_KEY=ваш_мастер_ключ
```

### 4. Запустить pipeline
```bash
python generate_mass_tutors.py   # загрузить 50 тестовых репетиторов
python search_config.py          # настроить индекс и модель
python check_status.py           # (опционально) проверить, что задачи прошли
python test_search.py            # сделать тестовый поиск
```
